User Guide

使用說明

忘記欄位、燈號或更新邏輯時，先回到這頁確認。
設計目的 用一個首頁掌握 00919 是否仍適合持有

00919 是高股息 ETF，不需要每天盯盤。本儀表板把每日價格、月度規模、 季度配息與 54C、前十大持股變化整合起來，讓首頁成為手機端也能快速判斷的總覽。

核心原則 首頁看結論，子頁查原因

首頁只保留最需要一眼確認的資訊；若燈號變黃或紅，再依文字提醒前往每日、每月、 每季、持股或每年頁查看細節。

首頁怎麼看

  • 倉位資訊：由交易紀錄自動計算股數、成本、市值、未實現損益、預估年配息、累積配息與含息損益。
  • 總燈號及股價資訊：正常時只顯示「所有數據正常」；異常時會說明哪個分頁、哪個數據需要檢查。
  • 資料更新狀態：確認價格、月規模、配息/54C、前十大持股、整體抓取與資料完整性是否正常。
  • 首頁重點總覽：放每個子分頁最值得回頭看的數字，例如含息報酬、最新配息、54C、AUM、受益人數、前十大集中度。

資料更新 SOP

  1. 開啟 `啟動00919儀表板.bat`，本機會先執行 `fetch_data.py` 抓取最新資料。
  2. 進入首頁後，也可以按「更新資料」手動補抓。
  3. 更新範圍包含每日價格/淨值/折溢價/成交量、每月 AUM/受益人數、配息與 54C、前十大持股與產業配置。
  4. 若日後搬到雲端，按鈕會改成呼叫雲端後端或雲端函式，邏輯不變。
  5. 如果某幾天沒有開網頁，更新流程應補抓缺漏資料，而不是只抓當天。

資料完整性警示

這是防止「資料沒抓到卻被拿去計算」的保護機制。

  • 市價缺漏：目前市值、未實現損益、含息報酬會失真，總燈號會轉紅。
  • 淨值或折溢價缺漏：折溢價圖表與每日燈號會失真，通常轉黃或紅。
  • 淨值/折溢價更新落後：市價比淨值或折溢價新 1 天通常視為資料傳遞時間差；落後 2 天以上才列入需留意。
  • 成交量缺漏：成交量觀察會缺資料，通常轉黃。
  • AUM / 受益人數缺漏：ETF 規模健康與月度燈號會失真。
  • 配息 / 54C 缺漏：每季配息、年度 54C、補充保費估算會失真。
  • 前十大持股缺漏：集中度、第一大持股與汰換紀錄會缺資料。

燈號規則

  • 綠燈：目前沒有超過設定門檻，首頁顯示「所有數據正常」。
  • 黃燈：有需要觀察的項目，例如折溢價偏大、月度含息報酬轉弱、前十大集中度偏高、資料稍微過期。市價與淨值/折溢價差 1 天不列黃燈，落後 2 天以上才提醒。
  • 紅燈：關鍵資料缺漏，或異常已經會明顯影響市值、損益、含息報酬等核心計算。
  • 門檻設定：折溢價、54C、補充保費、受益人數、前十大集中度等可到「燈號設定」調整。

各分頁用途

  • 每日總覽：看市價、淨值、折溢價與成交量，主要用來判斷價格是否偏離淨值太多。
  • 交易紀錄：手動輸入買入/賣出日期、股數、價格與分類，首頁所有倉位資訊都由這裡計算。
  • 每月：看 AUM、受益人數與自己的含息報酬，確認是否越抱越不健康。
  • 每季：看配息、54C、收益平準金、資本利得與補充保費估算。
  • 持股：看前十大持股、產業分布、集中度與新增/淘汰紀錄。
  • 每年：看年度配息總額、年度 54C、補充保費觀察與報稅季整理。

雲端版規劃

  • 手機端以首頁為主，電腦端保留完整分頁。
  • 資料更新採「手動更新按鈕 + 缺漏補抓 + 資料新鮮度提醒」。
  • 不優先依賴排程，避免免費雲端額度被用光。
  • 只要雲端提供同樣格式的資料檔，前端燈號與完整性警示可以直接沿用。
